# Как участвовать

1. Выберите Issue с меткой `good first issue` и напишите в нём, что берёте задачу.
2. Сделайте форк, ветку от свежей `main` и правку только по Issue.
3. Проверьте: `node example.js`.
4. Откройте Pull Request в `main` оригинала с `Closes #<номер>` в описании.

Ошибку сообщайте через New issue: что делали, что ждали, что получили.
